
# Bank REST API
## Stack

-   **Backend**: Java 17, Spring Boot 3, Spring Security (JWT), Spring Data JPA
-   **Database**: PostgreSQL 15+
-   **Миграции**: Liquibase
-   **Контейнеризация**: Docker, Docker Compose
-   **Тестирование**: JUnit 5, Mockito, Testcontainers
-   **Документация API**: OpenAPI 3 (Swagger)
-   **Утилиты**: Lombok, MapStruct

## Core Features

### Пользовательские эндпоинты
-   **Аутентификация и Регистрация**
    -   Регистрация нового пользователя с уникальной проверкой по email и номеру телефона.
    -   Вход в систему по email и паролю, получение пары JWT (access и refresh токенов).
    -   Обновление access-токена с помощью валидного refresh-токена без необходимости повторного ввода пароля.
-   **Управление счетами**
    -   Создание новых банковских счетов в разных валютах (USD, EUR и т.д.).
    -   Получение списка всех своих счетов с актуальными балансами.
    -   Безопасное закрытие счета. Операция требует, чтобы баланс был равен нулю и к счету не было привязано активных карт.
-   **Управление картами**
    -   Выпуск новой дебетовой карты, привязанной к одному из счетов пользователя.
    -   Получение списка своих карт. Номер карты в ответе маскируется для безопасности (отображаются только последние 4 цифры).
    -   Блокировка своей карты в случае утери или кражи.
-   **Финансовые операции**
    -   Перевод средств с одного своего счета на любой другой счет в системе по его номеру.
    -   Операции являются атомарными (используют `@Transactional`) и защищены от состояния гонки (race conditions) с помощью пессимистических блокировок на уровне БД.

### Админские эндпоинты
-   **Управление пользователями**
    -   Просмотр всех пользователей системы с пагинацией.
    -   Изменение статуса пользователя (например, `ACTIVE` на `SUSPENDED` для блокировки доступа).
-   **Полное управление картами**
    -   Просмотр карт любого пользователя.
    -   Принудительное изменение статуса любой карты.
    -   Удаление карты из системы.
-   **Управление карточными продуктами**
    -   Создание и обновление типов кард ("Visa Classic", "Mastercard Gold")

## Prerequisites

-   JDK 17 или новее
-   Maven 3.8+
-   Docker
-   Docker Compose

## Запуск проекта
### Для разработки

Используйте `docker-compose.dev.yml`

1.  **Создать файл `.env`** из `env.example`
    ```bash
    cp .env.example .env
    ```
2.  **Запустить docker-compose:**
    ```bash
    docker-compose -f docker-compose.dev.yml up --build
    ```
3.  **API будет доступно по адресу:** `http://localhost:8081/api`
4.  **Swagger UI:** `http://localhost:8081/api/swagger-ui.html`

### Для production-окружения

Основной `docker-compose.yml`.

1.  **Соберите проект**:
    ```bash
    mvn clean package
    ```
2.  **Запустите docker-compose:**
    ```bash
    docker-compose up --build
    ```
